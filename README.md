# lssd-dashboard
Das LSSD Dashboard ist eine webbasierte Verwaltungsplattform für das Los Santos Sheriff Department im GTA Roleplay. Es ermöglicht strukturierte Organisation, klare Regelwerke und effiziente interne Abläufe durch digitale Dokumentation, Rangverwaltung und dienstliche Informationen – 24/7 erreichbar und geräteübergreifend nutzbar.
